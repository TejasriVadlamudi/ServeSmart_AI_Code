The Python forecasting and verification scripts need only requirements.txt.
The reporting-only comparison workbook is authored with @oai/artifact-tool using the bundled Node environment in this session. Build_Comparison_Workbook.mjs reads the JSON generated by Prepare_Final_Reports.py. On another computer, install a compatible @oai/artifact-tool package in a separate Node environment before rebuilding this XLSX; that authoring package is not a Python dependency. The supplied XLSX is self-contained and readable in Excel without these authoring tools. It does not train models or select a different winner.
